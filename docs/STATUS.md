## 相较原版的主要调整

| 方面 | 当前实现与差异 |
| --- | --- |
| 运行方式 | 使用 JavaScript、Canvas、Web Audio 与 Electron 实现编辑器，提供浏览器运行方式及 Windows 单文件便携包。保留 iBMSC 名称、轨道编辑风格与原版图标；不以逐像素复刻旧 WinForms 界面为目标。 |
| 谱面类型 | 用户侧为 SINGLE、DOUBLE、PMS。显式选择分别映射 PLAYER 1、3、3；导入旧 PLAYER 2/4 显示 Couple Play/Battle Play，并在普通编辑与保存时保留原值。PMS 通过扩展名或工程元数据识别，自动切换 Pomu，完整显示九键，默认保存 .pms。 |
| 视图与缩放 | 视图菜单集中显示开关、BGM 列数与分屏同步；移除“显示 2P”。BGM 根据谱面和窗口补列，数字同步实际列数。Ctrl＋滚轮改为 50–300% 整体 Zoom，音符、字体、列宽、格线一起缩放；纵向默认 4 和独立纵横调整保留。移除 Ctrl＋Shift＋滚轮及 / 备用格线切换。 |
| 菜单与交互 | 按用户确认重排工具栏；输入设置归入选项；错误检查为编辑菜单中的动作。地球按钮直接切换语言；空白处右键不弹视图菜单。默认禁止纵向移动、单击试听；新试听停止前一个 Key 音。 |
| 查找与诊断 | 还原选中状态、长短/隐藏音符、小节/编号/数值及列筛选。删除分为“删除已选中”和“按条件删除”，避免选择动作改变筛选结果后误以为删除失效。修正长条内部普通音符漏检，保留错误高亮。 |
| 编码与保存 | 默认保存 UTF-8，可在保存流程选择 UTF-8 或 Shift-JIS（Windows-31J，兼容 LR2）。Windows 原生保存窗口包含编码栏，浏览器下载也按所选编码输出；不可表示字符拒绝有损写入。读取支持显式 UTF-8、Shift-JIS、GBK；自动检测仅尝试 UTF-8/Shift-JIS，不保证自动判断 GBK。 |
| 音频 | 统一使用内置预览，移除 uBMplay/o2play 等外部播放器配置与启动链。支持 BPM/STOP 时间轴、指定位置播放接续持续声音、单音试听；补充 Microsoft ADPCM WAV 解码和目录内大小写/Unicode/扩展名回退。音频兼容范围仍需真实素材验收。 |
| 工程、配置与主题 | 支持 BASE16/36/62 和独立 .ibmscx 工程；原 .ibmsc 格式继续保持兼容边界，不增加私有数据块。支持自定义皮肤编辑、原版主题/配置 XML 往返与未知内容保留。默认皮肤 IIDX；自动保存独立恢复副本，默认 2 分钟且可调，不覆盖用户谱面。 |
| 本地化与署名 | 菜单、窗口、错误反馈和 About 接入中日英韩；英文侧栏使用 Measure / Extended Code。保留原作者、贡献者与依赖声明，移植维护署名 SeaRay。 |
