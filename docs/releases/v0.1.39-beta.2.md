# iBMSC Beta 2 (0.1.39)

[English](#english) · [简体中文](#简体中文)

## English

### Changes since Beta 1

- Cleaned up the macOS DMG: the installation window contains only **iBMSC.app** and the **Applications** shortcut. Credits and notices stay inside the app bundle.
- Added the first **Linux x64** desktop packages: AppImage and DEB. Linux ARM packages are not yet available.
- The desktop app now follows your system language on first launch, with English as the fallback. Manual language choices are remembered.
- Web touch controls support one-finger panning, two-finger pinch zoom, and hold-and-drag selection or note movement. Long-press editing no longer triggers browser text selection.
- The web version can load a chart's keysounds by selecting their folder, including subfolders, instead of selecting every audio file separately. Individual file selection remains available for browsers without folder selection.

### Downloads

Download from the [Beta 2 release](https://github.com/RM-801/iBMSC-electron/releases/tag/v0.1.39-beta.2):

| Platform | File | Start |
| --- | --- | --- |
| Windows x64 | `iBMSC-0.1.39-setup-x64.exe` | Run the installer. |
| Windows x64 portable | `iBMSC-0.1.39-portable-x64.exe` | Double-click to run. |
| macOS Apple Silicon | `iBMSC-0.1.39-mac-arm64.dmg` | Drag iBMSC.app into Applications. |
| macOS Intel | `iBMSC-0.1.39-mac-x64.dmg` | Drag iBMSC.app into Applications. |
| Linux x64 AppImage | `iBMSC-0.1.39-linux-x64.AppImage` | Allow the file to run as a program, then open it. |
| Linux x64 DEB | `iBMSC-0.1.39-linux-x64.deb` | Open with your system's software installer on a system that supports `.deb`. |

Node.js is not required. Updates must be downloaded manually. The [web version](https://rm-801.github.io/iBMSC-electron/) needs no installation.

### Known limitations

- Test with copies of your charts first. Real audio, touch interactions, and complete desktop installation/editing workflows still need hands-on validation across devices.
- Windows packages are unsigned. macOS packages use ad hoc signing and are not notarized by Apple.
- `LNTYPE 2` is unsupported. Built-in preview does not render BGA images or videos. Conditional directives are preserved as text but are not evaluated.
- Select GBK explicitly when opening GBK charts; automatic detection is not guaranteed. Some original time-selection behavior and early `.ibmsc` project compatibility remain under review.

Report problems in [Issues](https://github.com/RM-801/iBMSC-electron/issues) with the app version, operating system, and steps to reproduce. Original authors: **iBMS / iBMS.[4th Age]**. Port and maintenance: **SeaRay**. [Credits and licensing notes](../../CREDITS.md).

## 简体中文

### 相比 Beta 1 的改动

- 整理 macOS DMG：安装窗口仅保留 **iBMSC.app** 和 **Applications** 快捷方式，致谢与声明保留在应用包内部。
- 首次提供 **Linux x64** 的 AppImage 和 DEB 包，暂未提供 Linux ARM 包。
- 桌面版首次启动跟随系统语言，未支持的语言回退到英文；记住手动选择的语言。
- 网页版支持单指平移、双指捏合缩放、长按拖动框选或移动音符，并修复长按编辑时触发浏览器文字选择的问题。
- 网页版可选择音源所在文件夹，一并关联子目录中的 Key 音，无需逐个勾选；不支持文件夹选择的浏览器仍可选择单独的文件。

在 [Beta 2 发布页](https://github.com/RM-801/iBMSC-electron/releases/tag/v0.1.39-beta.2) 下载：

| 平台 | 文件 | 使用方式 |
| --- | --- | --- |
| Windows x64 安装版 | `iBMSC-0.1.39-setup-x64.exe` | 运行安装程序。 |
| Windows x64 便携版 | `iBMSC-0.1.39-portable-x64.exe` | 双击运行。 |
| macOS Apple Silicon | `iBMSC-0.1.39-mac-arm64.dmg` | 将 iBMSC.app 拖入 Applications。 |
| macOS Intel | `iBMSC-0.1.39-mac-x64.dmg` | 将 iBMSC.app 拖入 Applications。 |
| Linux x64 AppImage | `iBMSC-0.1.39-linux-x64.AppImage` | 允许文件作为程序执行，然后运行。 |
| Linux x64 DEB | `iBMSC-0.1.39-linux-x64.deb` | 在支持 `.deb` 的系统中，用软件安装程序打开。 |

无需安装 Node.js；更新需手动下载。[网页版](https://rm-801.github.io/iBMSC-electron/) 无需安装。

### 已知限制

- 请先用谱面副本测试。实际音频、触屏交互、桌面安装与完整制谱流程仍需在不同设备上验收。
- Windows 包未签名；macOS 包采用临时签名，尚未经过 Apple 公证。
- 暂不支持 `LNTYPE 2`；内置预览不显示 BGA 图片或视频；条件分支保留原文但不展开执行。
- GBK 谱面需显式选择读取编码，不保证自动识别。原版时间选择的部分行为和早期 `.ibmsc` 工程兼容仍在核对中。
