# iBMSC Beta 1 (0.1.38)

这是 iBMSC 跨平台移植项目的第一版公开 Beta，由 SeaRay 移植与维护，基于 iBMSC 3.0.5 Delta。保留原版编辑风格，并改进菜单、缩放、编码和内置预览。本版本用于试用与反馈，尚未完成所有功能及平台验收。

## 下载

- **Windows 安装版**：iBMSC-0.1.38-setup-x64.exe。安装向导可选择目录，创建桌面与开始菜单快捷方式。
- **Windows 便携版**：iBMSC-0.1.38-portable-x64.exe。无需安装，双击运行。
- 两者均自带运行环境，无需安装 Node.js；本版尚未接入自动更新。
- SHA256SUMS.txt 提供下载文件的 SHA-256 校验值。
- **macOS Apple Silicon**：iBMSC-0.1.38-mac-arm64.dmg。
- **macOS Intel**：iBMSC-0.1.38-mac-x64.dmg。打开 DMG，将 iBMSC.app 拖入 Applications。
- macOS 校验值分别见 SHA256SUMS-mac-arm64.txt 和 SHA256SUMS-mac-x64.txt。
- **网页版**：[在线使用](https://rm-801.github.io/iBMSC-electron/)，无需安装。
- Linux 桌面包暂未发布。

## 主要功能与改进

- 选择、写入、长音符、NT/BMSE、LNOBJ、复制粘贴、撤销重做、变拍、统计和 MyO2 工具。
- SINGLE / DOUBLE / PMS 模式；PMS 自动使用 Pomu 九键皮肤并默认保存为 .pms，兼容旧 Couple/Battle 文件头。
- 重新整理菜单和工具栏，动态 BGM 列，Ctrl＋滚轮整体缩放音符、文字与格线。
- Ctrl＋F 多条件查找/替换，分别删除已选中音符或符合条件的音符；补充长条内部普通音符的冲突检查。
- UTF-8 / Shift-JIS 保存选择，内置音频预览、单音试听、Microsoft ADPCM WAV 解码。
- 自定义皮肤、中日英韩界面、原版设置 XML 兼容、独立恢复副本及 .ibmscx 工程。
- 沿用原版应用图标，保留原作者、贡献者与依赖声明。

## 已知限制与验证

- 请先用谱面副本验收保存、重开和目标播放器播放。
- 自动编码识别尝试 UTF-8 / Shift-JIS；GBK 需显式选择，不保证自动识别。
- 条件分支保留原文但不展开执行；LNTYPE 2 尚不支持；内置播放器尚不渲染 BGA 图片/视频。
- 原版时间选择的部分行为、早期 .ibmsc/撤销历史、真实音频兼容性及完整安装/文件关联流程仍待验收。
- Windows 包未签名；macOS 包采用临时签名，尚未进行 Developer ID 签名或 Apple 公证。macOS 的实际音频、交互和完整制谱流程仍待本机验收。
- 发布前自动测试为 270 项中的 268 项通过；两项 Windows 符号链接测试因 EPERM 未完成。真实浏览器菜单、缩放和语言切换已检查，Windows 包内程序启动自检通过。测试通过不代表全部功能与原版等价。

## macOS 构建验证

Apple Silicon 与 Intel 均通过 270/270 自动测试、codesign 完整性校验、DMG 校验及挂载后的应用启动检查。图标及主要运行文件与源码核对一致。[构建记录](https://github.com/RM-801/iBMSC-electron/actions/runs/37277838791)。

macOS 补充包构建自提交 `04269f1`，在 Beta 1 源码基础上更新 README、macOS 打包及验证脚本；未修改编辑器运行逻辑。
