# 开发交接（2026-09-20）

这是 iBMSC 的 JavaScript / Node.js / Electron 移植项目，当前版本 0.1.7。目标是尽量还原原版编辑能力，并提供 macOS 桌面应用；不能把当前状态称为完整移植或全部验收通过。

## 开始工作

使用 Node.js 22 或以上，在仓库根目录执行 `npm ci`、`npm test`、`npm run check`。`npm run dev` 启动浏览器预览，`npm start` 启动桌面应用，`npm run package:mac` 在 Mac 上打包。

已验证 108 项自动测试，Apple Silicon Mac 0.1.7 应用包启动成功；当前包仅为本地签名，尚无 Developer ID / 公证。生成的安装包、node_modules、用户谱面和音源不纳入仓库。

## 用户已确认的行为

- 启动为空白谱面；默认垂直缩放为 4。
- 写入吸附使用最近网格 round，这是用户明确接受的原版行为调整。
- 音符下沿对齐时间；小节线附近点击曾多次出错，改动坐标逻辑时必须回归。
- SP 默认隐藏 D1–D8，DP 显示；BGM 列按导入数据动态扩展并填充可视区；BGA / LAYER / POOR 默认折叠。
- 统计需要 A1–A8 明细，DP 还需要 D1–D8；LN 即长音符，原版端点计数与整条数量应说明清楚。
- 桌面打开谱面后读取相对音源路径；网页需要手动选择音源。WAV / OGG / MP3 同名扩展名回退已经实现。
- BGM 中允许临时存放 LN；BMS 保存时提醒会变为仅起点发声的单音符，编辑状态不静默丢失长条。
- BASE16 / 36 / 62；BASE62 区分大小写。独立 .ibmscx 保存 BASE62 与暂存 BGM 长条，原版二进制工程限 BASE36。
- macOS 使用系统菜单。保留原作者、贡献者、上游 README 和版权说明。
- MyO2 排除，波形低优先级。曾讨论 C++ 音频引擎，但尚未实施，不应当作已批准重写计划。
