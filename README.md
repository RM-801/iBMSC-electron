100 项自动测试通过，包括完整 BASE62 字符表、BASE 位于末尾、音源编号 Z/a 与 z/10 边界、保存重开、BGM 暂存 LN、查找替换撤销及 BPM/STOP 时序。真实音频和目标播放器验收仍未完成。非 BASE36 的原版二进制 .IBMSC 导出会拒绝并提示保存 BMS；不同 BASE 间的剪贴板粘贴暂时阻止，避免静默转换。未声称支持所有 BMS 扩展。

进制参考：[BMS Library BmsInt](https://www.lm-t.com/content/bmslibrary/doc/latest/com/lmt/lib/bms/BmsInt.html) 及 [BeMusicMeta.BASE](https://www.lm-t.com/content/bmslibrary/doc/latest/com/lmt/lib/bms/bemusic/BeMusicMeta.html)。
