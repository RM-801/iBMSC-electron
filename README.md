跨平台谱面编辑器，移植与维护：SeaRay。当前测试版本：**0.1.37**。

当前功能、相较原版的调整及验证边界见 [进展汇总](docs/STATUS.md)。下方旧版本记录保留开发历史，不代表当前待办状态。

## 0.1.37 菜单、工具栏与编辑区整体缩放

工具栏按查找→撤销→重做→统计→错误检查排列，MyO2 与地球语言按钮放到右端。输入设置移入选项；编辑菜单补齐删除、全选图标，并将带对号的错误检查动作放在统计下面。移除原错误检查启用开关，错误高亮保持启用。选项的语言子菜单增加地球图标。

英文侧栏改为 Measure、Extended Code；About 移植与维护署名为 SeaRay，项目链接不变。删除 / 格线切换的按钮、窗口、快捷键和配置应用；普通格线与侧栏纵横调整保留。取消画布获得焦点时的浏览器外框。

视图新增 Zoom，范围 50–300%，默认 100%，按 Ctrl＋滚轮每次调整 10 个百分点。音符高度、文字、列宽、网格、波形和标题同步缩放，独立于既有纵向/横向设置；取消 Ctrl＋Shift＋滚轮的横向缩放。鼠标位置与分屏滚动保持对应，缩放保存至设置，不修改谱面和撤销历史；修正小数缩放时第 0 小节边线的半像素命中边界。该行为替代旧版本记录中的 Ctrl 滚轮纵向 / Ctrl Shift 滚轮横向说明。

验证：新增音符缩放几何、裁剪、DPI 命中及偏好回归；控制器覆盖缩放后选择/删除、三窗格锚点、Ctrl Shift 无动作、上下限、源码/历史不变、语言按钮、错误检查与移除 / 快捷键。真实浏览器核验 200% 放大、重载保持设置、无焦点边框、菜单图标与新位置、语言切换和 SeaRay 署名，无控制台错误。截图 outputs/editor-zoom-0.1.37.jpg 与 outputs/menus-0.1.37.jpg。

## 0.1.27 查找窗口双删除操作

### 新增编辑操作

- 双击音符修改编号，双击 BPM/STOP 修改数值；NT 长音符保持两端关联，LNOBJ 结束标记保留。
- NT 右键删除整条长音符，Shift＋右键选取该音符音源；BMSE 仍按单端点操作。
- NT Shift＋拖动端点改变长度，支持组选中、跨小节、零长度转普通音符；交叉导致错误配对时取消操作。
- 框选覆盖长音符主体即可选中整条；拖动到视窗边缘可自动滚动。
- 小节列表支持 Ctrl/Command、Shift 多选，设置变拍可整组应用；范围变拍复用四种模式，一次撤销整批恢复。
- F1/F2/F3：时间/选择/写入；F5/F6/F7：从头/指定小节/停止；F8：NT/BMSE；数字键 1–8：移至 A1–A8。
